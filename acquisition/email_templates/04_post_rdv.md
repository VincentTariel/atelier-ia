# Template — Email post-RDV avec proposition

> À envoyer **dans les 24h** suivant l'entretien découverte.

---

**Objet** : `{prenom}, suite à notre échange — proposition pour {nom_entreprise}`

---

**Corps** :

```
Bonjour {prenom},

Merci pour notre échange de {jour}, c'était un vrai plaisir.

Pour récapituler ce qu'on s'est dit :

→ Vos cas prioritaires identifiés : 
   1. {cas_1}
   2. {cas_2}
   3. {cas_3}

→ Les workflows qu'on mettrait en place :
   - {workflow_1}
   - {workflow_2}

→ Le format de coaching qui colle le mieux à votre contexte :
   {Forfait découverte 2h | Forfait complet 4 sessions | Suivi mensuel}

Vous trouverez ci-joint la proposition détaillée avec le 
planning et les conditions.

Mes prochaines disponibilités pour démarrer : 
{créneau 1}, {créneau 2}, {créneau 3}.

Si vous avez la moindre question avant de vous décider, 
appelez-moi directement au +687 [téléphone] — c'est plus 
simple qu'un email.

Bien cordialement,
Vincent Tariel
Atelier IA
```

---

## Pièce jointe à préparer

- **PDF "Proposition coaching"** personnalisée :
  - Page 1 : récap de l'échange + cas prioritaires
  - Page 2 : programme détaillé des sessions
  - Page 3 : planning + tarif + CGV en bas
  - Page 4 : prochaines étapes (signature acompte)

## Notes

- **Récap structuré** = preuve d'écoute + ancrage des bénéfices futurs.
- **Trois créneaux** réduisent la friction de réponse.
- **Inviter à l'appel** plutôt qu'à un nouvel email = raccourcit le cycle de décision.
- Si pas de réponse → relance J+5 (court email), puis J+15 (dernière). Ne pas insister au-delà.
