# Persona — À qui on parle

## Profil type

- **Âge** : 35-55 ans
- **Lieu** : Nouméa et Grand Nouméa (Dumbéa, Mont-Dore, Païta). Présentiel = critère bloquant.
- **Statut** : dirigeant de TPE/PME, profession libérale, cadre intermédiaire/sup avec autonomie sur ses outils, ou indépendant établi.
- **Pré-requis tech** : sait utiliser un ordinateur, Word, Excel, sa boîte mail. **Pas de pré-requis dev**.
- **Maturité IA** : a entendu parler de ChatGPT, l'a peut-être essayé deux fois. Curieux mais sceptique. **Pas un early-adopter**.

## Secteurs prioritaires (à valider après les 10 premières ventes)

| Secteur | Pourquoi c'est un bon fit | Cas d'usage typiques |
|---|---|---|
| **Cabinets d'expertise comptable / juridique / notariat** | Forte charge rédactionnelle, dossiers récurrents, sensibilité confidentialité | Rédaction de courriers types, synthèse de jurisprudence, préparation de RDV client |
| **Cabinets de conseil / consulting indépendants** | Beaucoup de notes, rapports, propositions commerciales | Mise en forme de propositions, synthèse de réunions, recherche client |
| **Agences immobilières / professions immobilières** | Beaucoup d'annonces, de descriptions, de courriers | Rédaction d'annonces, courriers de relance, fiches descriptives |
| **Artisans / PME du BTP** (dirigeants) | Devis, courriers admin, gestion de chantier — beaucoup de paperasse | Rédaction de devis, courriers admin, suivi de chantier |
| **RH / managers en PME** | Fiches de poste, comptes-rendus d'entretien, communication interne | Rédaction de fiches de poste, synthèse d'entretiens, communications |
| **Communication / marketing en PME** | Production de contenu hebdo (réseaux, newsletter, blog) | Rédaction posts, idées de contenu, retravail de copy |

## Déclencheurs d'achat

- "Je passe deux heures par jour à écrire des emails / courriers."
- "Je n'arrive plus à suivre la rédaction de tous les documents."
- "Mon assistant·e est débordé·e / je n'ai pas les moyens d'embaucher."
- "J'ai essayé ChatGPT, ça ne donne rien d'utilisable."
- "Mes confrères en métropole utilisent l'IA, j'ai l'impression de prendre du retard."

## Objections fréquentes (voir `faq.md` pour les réponses)

1. **"L'IA c'est pas fiable / ça invente"** → vrai si mal utilisé, faux si encadré dans un Project avec contexte.
2. **"C'est confidentiel, je ne peux pas mettre mes dossiers là-dedans"** → Claude Desktop ≠ ChatGPT public, données pas utilisées pour l'entraînement.
3. **"Je n'ai pas le temps d'apprendre un nouvel outil"** → 4h de coaching = 30 min de gain par jour.
4. **"C'est cher pour ce que c'est"** → comparaison avec le coût horaire d'un assistant ou de son propre temps.
5. **"Pourquoi pas un cours en ligne / YouTube ?"** → on travaille sur VOS dossiers, pas sur des exemples génériques.

## Anti-persona (à qui on ne vend PAS)

- Développeurs / profils techniques cherchant Claude Code → pas le bon coach pour eux.
- Étudiants / jeunes en reconversion sans budget → pas la cible B2B.
- Grandes entreprises cherchant un déploiement à 200 utilisateurs → trop lourd pour un solopreneur, on perd le 1-to-1.
- "Curieux de l'IA" sans cas d'usage concret → ça finit en discussion philosophique non payée.
